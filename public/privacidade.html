Política de Privacidade

Marcos Leonam – Tráfego Pago · CNPJ 59.004.207/0001-87 · São Luís/MA · Atualizada em 29/09/2026

1. Quem somos

Marcos Leonam – Tráfego Pago é uma agência de tráfego pago que gerencia campanhas de anúncios (Google Ads e Meta Ads) para os próprios clientes. Contato: leonammlnl@gmail.com.

2. Ferramenta interna "Marcos Ads"

Usamos uma ferramenta interna, de uso exclusivo da agência, que se conecta à Google Ads API com a conta Google do próprio administrador da agência. Ela serve para gerar relatórios de desempenho, auditar configurações e criar ou ajustar campanhas nas contas dos clientes vinculadas à nossa conta de administrador (MCC). A ferramenta não tem usuários externos e não é oferecida a terceiros.

3. Dados acessados

  • Dados de desempenho e configuração das contas de anúncios dos clientes (campanhas, anúncios, palavras-chave, custos, cliques, conversões).
  • Endereço de e-mail da conta Google do administrador da agência, usado apenas para autenticação.

Não coletamos dados pessoais de usuários finais nem de visitantes de sites por meio dessa ferramenta.

4. Como usamos os dados

Os dados de cada conta são usados somente para prestar o serviço contratado àquele mesmo cliente: relatórios, recomendações e gestão das campanhas. Não vendemos, não alugamos e não compartilhamos dados com terceiros, nem cruzamos dados de um cliente com outro.

5. Armazenamento e segurança

As credenciais de acesso ficam em servidor próprio no Brasil, com acesso restrito ao administrador. Relatórios são guardados apenas pelo tempo necessário à prestação do serviço.

6. Uso de dados do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

7. Seus direitos (LGPD)

O cliente pode, a qualquer momento, remover o vínculo da sua conta com a nossa conta de administrador, o que encerra o acesso imediatamente, e pedir a exclusão dos relatórios guardados pelo e-mail acima. O administrador pode revogar o acesso da ferramenta em myaccount.google.com/permissions.

Privacy Policy (English summary)

"Marcos Ads" is an internal tool used only by Marcos Leonam – Tráfego Pago to report on and manage the Google Ads accounts of its own clients, linked to our manager account. It accesses advertising performance and configuration data and the administrator's email for authentication only. Data is used solely to serve the same client, is never sold or shared with third parties, and is stored on a private server in Brazil. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: leonammlnl@gmail.com.
